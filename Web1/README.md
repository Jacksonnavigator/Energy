# HydraNet Command Center

I want you to build a polished, customer-facing energy operations web dashboard for a company called HydraNet Energy Intelligence. The app should feel like a premium SaaS platform for monitoring and managing connected electrical assets in real time, not a generic admin panel.

Core product goal:
Create a professional web dashboard for customers managing multiple electrical devices, relay-controlled assets, energy consumption, costs, alerts, exports, and platform settings. The interface should look modern, trustworthy, and operationally mature.

Main user:
A customer or operations manager who needs to monitor connected devices, energy use, costs, relay states, and system health from one place.

Design direction:

Premium SaaS aesthetic

Clean, executive-friendly layout

Minimal text and selective information density

Modern neutral palette with green/amber accents

Strong hierarchy, clear labels, modern cards, subtle shadows, rounded corners

Very polished and professional, not cluttered

Light and dark mode support is a plus

Mobile-responsive layout

Use good spacing, calm visual rhythm, and focus on clarity
